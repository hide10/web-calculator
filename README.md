# WEB電卓

GitHub Pages で公開しているシンプルな WEB 電卓です。

公開URL: https://hide10.github.io/web-calculator/

## 機能

| 機能 | 説明 |
|------|------|
| 四則演算 | `+`, `-`, `×`, `÷` |
| 連続演算 | `1 / 3 * 3` のような入力を左から順に正しく計算 |
| AC | 入力と演算状態を全クリア |
| ⌫ | 1文字削除 |
| % | 現在値を 100 で割る |
| . | 小数点入力 |
| キーボード対応 | `0-9`, `+`, `-`, `*`, `/`, `.`, `Enter`, `=`, `Escape`, `Backspace` |
| エラー処理 | ゼロ除算時に `Error` を表示 |
| レスポンシブ | スマホ幅でも操作しやすいレイアウト |

## 使い方

ブラウザで `index.html` を開くだけで動きます。

連続演算は一般的な電卓と同じく、入力順に確定していきます。

- `1 + 2 * 3 =` は `(1 + 2) * 3` として `9`
- `1 / 3 * 3 =` は `(1 / 3) * 3` として `1`

## ローカルで確認する

特別なビルドは不要です。静的ファイルだけで動作します。

```bash
cd ~/web-calculator
python3 -m http.server 8000
```

その後、`http://localhost:8000` を開いて確認できます。
